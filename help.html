Getting Started

The canvas behind everything shows a live, constantly-updating preview of your design. Everything you change in the Layers window — layers, colors, filters, animation — renders instantly, so there's no separate "preview" step.

A design is built from layers, stacked from bottom to top just like Photoshop or GIMP. Start with the Canvas menu to pick a resolution (or type a custom width/height), then use + Add Layer in the Layers window to build up your background one layer at a time.

Hover over almost anything in the Layers window — labels, sliders, buttons, dropdowns — and a short tooltip will explain what it does. That's the fastest way to learn the interface hands-on.

Tip: Nothing you do here is destructive until you export. Feel free to experiment — Undo (Ctrl/Cmd+Z) covers the last 50 changes.

View & Layout

The menu bar (File | Edit | View | ... | Help) runs full-width across the very top of the window. Everything below it is the live preview (the stage), with the Layers window floating on top of it.

The Layers window can be dragged anywhere by its titlebar — it's constrained so it can never be dragged outside the app's own window, so its titlebar (and your way to move it back) is never out of reach. Click the × in its corner to close it; this only ever hides it, nothing is lost. Bring it back from View > Show Layers, which shows a checkmark whenever it's open. Its position and open/closed state are both remembered the next time you open the app.

Use the View menu to control how the preview is scaled: Zoom to Fit shrinks it to fit the available space (the default), Zoom to Actual Size shows it at exactly 100% (one image pixel per screen pixel), and Zoom In / Zoom Out step through preset percentages — the current zoom level is always shown in the menu. None of this changes the canvas's actual resolution, only how large it's displayed.

Layers

Every layer type lives behind the + Add Layer button:

  • Solid Fill — a single flat color.
  • Linear / Radial Gradient — a smooth color blend, with up to 6 color stops.
  • Diagonal Checker, Stripes, Dots, Hex Grid, Sci-Fi HUD Grid — repeating geometric patterns, fillable with a flat color or their own gradient.
  • Grain / Noise — static grain, or smooth Perlin noise (Clouds, Turbulence/Smoke, Marble).
  • Image Overlay — a picture from your computer, with control over fit, scale, offset, and flip.
  • Group — a folder that holds other layers and applies one shared opacity/blend mode on top of them.

Each layer card has a header with quick controls: the ⋮⋮ handle drags it to reorder (or use the ↑/↓ arrows), the eye checkbox shows/hides it, and the × deletes it. Click the layer name area to expand or collapse its full controls.

Every layer also has an Opacity slider and a Blend mode (Normal, Overlay, Multiply, Screen, Difference, Color Dodge/Burn, Hard/Soft Light, Exclusion) that controls how it combines with whatever is beneath it.

Grouping

Check the small select-boxes on two or more layers, then click Group Selected to fold them into a folder. Groups can be nested, duplicated, and ungrouped again at any time.

Tip: Top of the list = top of the stack. Use the arrows to reorder, the eye to hide, and blend mode + opacity to control how each layer combines with the ones below it. Turn on a layer's "Use as Mask" toggle to clip the layer directly beneath it to this layer's shape instead — switch its mode to Inverted to punch a hole through that layer instead of clipping to it. Check the box on any layers to group them into a folder with its own shared opacity and blend.

Masks

Any layer can become a mask for the layer directly beneath it in the stack — turn on its Use as Mask checkbox. A mask layer isn't drawn itself; instead its shape controls the layer below it, and a dropdown next to the checkbox picks how:

  • Standard — keeps only where the mask and the layer below overlap (the classic clipping behavior).
  • Inverted — the opposite: punches a hole through the layer below wherever the mask is opaque, leaving everything else untouched.

A mask must sit immediately above the layer it affects. The layer list shows a small MASK or INVERTED MASK badge so you can tell at a glance which mode is active. Blend mode doesn't apply to a mask layer itself.

Tip: A gradient mask with a soft alpha falloff (fade one color stop's opacity toward 0%) makes for a smooth vignette or fade effect on the layer beneath it.

Filters

Every layer has its own collapsible CSS Filters section: Blur, Brightness, Contrast, Grayscale, Hue Rotate, Invert, Filter Opacity, Saturate, Sepia, and an optional Drop Shadow (offset, blur, color). These apply on top of whatever the layer already looks like, including a whole group as one flattened effect.

There's also a Custom SVG Filter box for pasting your own SVG <filter> markup, applied via url(#id). Since the page usually runs straight from a local file, the filter markup itself is stored right in your design rather than referencing an external file.

Animation

Turn on Animate on any layer to make it move in a seamless, perfectly-looping cycle. The shared Loop Length control, in the Animation menu at the top of the page, sets how long one full loop takes for every animated layer; each layer's own Cycles value is how many times its motion repeats within that length.

Motion StyleWhat it does
Scroll / PanScrolls a tile pattern, or drifts Perlin noise (only available on pattern & noise layers)
PulseBreathes the layer's scale and opacity in and out
SpinRotates the whole layer a full turn per cycle
OrbitDrifts the layer's position in a small circle
CustomPercent keyframes or your own per-frame expressions

Two small icon buttons sit right next to the Animation menu: ▶ plays/pauses the live preview (starts paused by default — it turns into ⏸ while playing), and ● records exactly one loop to a .webm video file that repeats with no visible seam. The record button glows bright red while a recording is in progress, and is a dim, muted dot the rest of the time.

Tip: Cycles is always a whole number on purpose — a fractional cycle count would make position match at the loop boundary but velocity reverse, which shows up as a visible jump.

Custom animation: every numeric layer property

Custom accepts either percent keyframes (one or more 0% { ... } blocks) or, with no % stops at all, one property: expression; line per property using t (0–1 progress through a single cycle) and cycles, plus sin/cos/tan/abs/min/max/sqrt/pow/PI/floor/ceil/round. Both forms can drive the five whole-layer transform properties — opacity, scale, rotate, x, y — and also any of the layer's own numeric fields below, whichever apply to that layer's type. Animating one of these never changes the saved design, undo history, or exported JSON — it only affects what's drawn for that one frame.

Example: 0% { opacity: 100; blur: 0; } 50% { opacity: 60; blur: 12; huerotate: 180; } 100% { opacity: 100; blur: 0; } breathes a layer's opacity, blurs it, and drifts its hue over one cycle, then returns exactly to where it started.

Tip: a property name that doesn't apply to the current layer, or isn't recognized at all (a typo, or a gradient color-stop index — those aren't animatable since a design's stop count can vary), is silently skipped rather than breaking the animation. If the app's Debug Log is enabled (Help > Debug Log), skipped/unknown names are recorded there too, which is the quickest way to catch a typo.

Export & Share

Most of this lives in the File menu (the ● Record button is the exception — see Animation above):

  • Save… / Save As… / Load… — a full backup of the design (every layer and setting) as a local .json file. Save As asks for a new name first, then saves under it -- and updates the Canvas menu's File Name field to match, so PNG/CSS/Rainmeter exports pick up the new name too. The saved file's content is compressed (the same format Copy Code uses) rather than plain readable JSON, so it stays small even with several layers -- Load reads this format automatically, and still opens an older, plain-JSON save from before this change.
  • Export PNG — a static image at your chosen resolution.
  • Export CSS — bakes the design into a CSS background-image data URI you can drop straight into a stylesheet.
  • Export Rainmeter .ini — a Rainmeter Image meter, paired with its PNG.
  • Copy Share Link / Copy Code — encode the whole design (including embedded images) into a link or a short text code you can send to someone else. They can load it back in with Import a Link or Code.

Opening a share link directly hides all editor UI and fills the window with just the generated image — handy for using it as a live wallpaper or embedding it in an <iframe>.

Tips & Tricks

This section is a good place for your own house tips — add whatever you find useful as you go. A few to start with:

  • Use View > Palette Presets to constrain Randomize to a themed color set (Spectrum HUD, Industrial Automation, Neon) instead of fully random colors.
  • Edit > Effects splits Randomize into three options: Palette (colors only), Layers (opacity/blend/angles/sizes/positions only), and All — useful when you like a shape but want to try new colors, or vice versa.
  • Layer a low-opacity Grain/Noise layer with Normal or Overlay blend on top of a flat gradient for an instant subtle texture.
  • Turn on Performance Mode (Settings menu) if the canvas feels sluggish while dragging a slider on a heavy Perlin noise layer.
  • Auto-Save (Settings menu) continuously backs up your current design to this browser, so an accidental refresh doesn't lose your work.
